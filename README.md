# Portfolio

Portfolio pessoal de **Felipe Carreiro** — Lead Game Producer & Game Designer com mais de 10 anos de experiência produzindo jogos para PC, consoles e mobile.

Site: https://hedrosgames.github.io/portfolio/

## Seções

- **Home** — resumo, números e apresentação
- **About** — perfil e background
- **Projects** — projetos em destaque (Chessarama, Case Solved, Catalog, Logic Pic, NFT, Mobile, Outsourcing)
- **Experience** — trajetória profissional e docência
- **Contact** — e-mail e LinkedIn

## Estrutura

| Pasta/Arquivo | Conteúdo |
|---|---|
| `index.html` | Site principal em página única (EN/PT) |
| `chessarama/`, `casesolved/`, `othergames/`, `catalog/`, `logicpic/`, `nftgames/`, `mobilegames/`, `outsourcing/` | Imagens dos projetos |
| `contract/` | Termo de estágio |
| `forms/` | Página de formulário de inscrição (Case Solved) |
| `helpgit/` | Guia de Git para Unity (PT-BR) |
| `vaga/` | Página de vaga |

## Stack

- HTML/CSS/JS vanilla em arquivo único
- Tailwind CSS via CDN
- i18n inline (inglês / português)

## Rodando localmente

Abra o `index.html` no navegador. Sem build.
